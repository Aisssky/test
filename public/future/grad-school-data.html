为什么以拟录取均分排序：复试线只是入场券，热门方向实际录取均分常比线高 30–50 分（大工软院 301→356、华师计专 260→350、北邮数媒 325→356）。均分才是真实门槛。
均分口径：数字为「一志愿拟录取考生初试均分」，括号内为最低–最高区间；带 * 的为复试均分（该校未公示录取均分）；带 ≈ 的为由官方录取分布推得的近似值；「未公示」的院校按复试线排序并单独排在已知均分的条目之后。
实习政策列：仅深大（戴涛组 / 光明实验室）与华师智能交互学院有官方公开出处，其余均标「需套磁确认」——放不放实习是个别导师行为，报考前务必通过导师评价网 / 在读学生核实。
报录比口径：优先采用各校公示的「报名 / 录取」数据；未公开报名人数的院校给复试/录取人数与录取率，未编造报录比。

03使用说明

  1. 按均分定目标，按线报志愿。备考目标分应设在拟录取均分 +5～10 分，而不是复试线；复试线附近进复试的淘汰率往往过半（华师计专复录比 3:1、大工全院 1.79 且有笔试硬闸）。
  2. 「待定」= 2027 首届。华师智能交互学院 2027 年首届招生（统考 18 名），无往年参照，历史规律首届往往偏低——窗口与风险同在。
  3. 408 是公共科目。深大 / 北工大 / 华师软院 / 中山 / 杭电 / 川大 / 吉大 / 中南 / 大工（26 起）均考 408；华师计院 085404 / 智能交互学院考数二 + 英二 + 408，对数学压力更小；例外：华师数科（自命题）、北邮（26/27 起逐步改 408）、上大数媒（875）。
  4. 改考 408 的窗口。大工 2026 起自命题改 408，改考首年通常分数下探；北邮 26/27 逐步改考同理。
  5. 专硕代码别记错。计算机技术 085404、软件工程 085405、人工智能 085410、电子信息 085400 是专硕；081200 / 083500 / 089901 是学硕。
  6. 双非友好度是经验画像，来自各校复试规则（是否三随机、是否保护一志愿）与往届反馈，非官方结论，报考当年务必回学院看最新复试方案。
  7. 导师名单、名额、科目每年调整，报考当年回研招网（yz.chsi.com.cn）与各校研究生招生网复核。
